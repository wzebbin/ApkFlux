安装并打开第一个 APK

  1. 打开 DMG，将 ApkFlux 拖到「应用程序」。免费版使用临时签名，首次打开可能出现开发者验证提示。查看 Apple 的说明。
  2. 拖入 APK，或点击「导入 APK」。1.0.0 可直接浏览包内文件。反编译和解码需要 Java、JADX 或 Apktool，验签与重建需要 Android SDK Build Tools。前往「设置 → 外部工具」配置。查看工具配置。
  3. 从「设置 → 应用更新」打开 GitHub 获取新版，退出 ApkFlux 后替换应用即可。
