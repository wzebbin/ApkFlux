# 变更记录

## 0.5.2 · Apple Silicon 收尾验收

- 启动时清理超过 30 天未使用的可重建结果，保留已保存编辑及其解码基础。
- 增加 256 MiB 大 APK、24 编辑标签和跨重启缓存清理压力测试。
- 添加 GitHub Pages 官网和 Apple Silicon 的 GitHub Releases 签名、公证与更新发布流程。

## 0.5.1 · Apple Silicon 本地验收版

- 移除 AI 面板、差异审阅入口及后台服务通信。文本差异继续在本地查看。
- V1.0 的构建、验收与发布范围调整为 Apple Silicon macOS。Intel Mac 和 Windows 延后。

## 0.5.0 · V1.0 本地验收版

- 增加工作区全局搜索，搜索原始 APK 和已生成视图的路径，以及 Java、Smali 和解码资源中的文本。结果显示来源和行号，打开时同步定位文件树。
- 版本对比显示基准和当前 APK 的解码覆盖情况，支持筛选代码、资源和 SO 文件。解码资源参与内容哈希比较。
- 选中的文本差异可以带入 AI 的待发送内容，交由用户先审阅。返回分析页时保留原报告。
- 收拢文件、APK 分析和构建三个一级入口。编辑器支持多标签独立草稿、滚动位置和关闭提示，文件树支持展开、折叠及搜索定位。

## 0.4.3

- 窄窗口默认收起 APK 信息，按需在右侧打开。视图名在窄栏中换行，文件名过长时显示省略号。
- 合并原始文件和解码文件的预览处理，统一 SO 文件识别规则。修复搜索结果跳转和日志达到缓冲上限后的滚动。

## 0.4.2

- 将文件视图命名为「原始 APK」「反编译 Java」「Smali / 资源」。编辑器标签和路径栏都标明当前文件的来源。

## 0.4.1

- 从 APK 文件树或「查看清单」直接打开解码后的 AndroidManifest.xml。Smali 和资源解码完成后，同一入口打开可编辑的工作副本。

## 0.4.0

- 接入本地 Ghidra，支持对 APK 的 SO 文件建立可搜索的函数索引，并按函数查看反汇编和 C 风格伪代码。
- 缓存 Ghidra 项目和已生成的函数内容。可从 APK 文件树或 SO 分析结果进入。

## 0.3.0

- 解码后的 Smali、清单和文本资源可编辑。支持保存、撤销重做、查找替换、图片替换、差异和未保存提示。
- 新增 Apktool 重建、zipalign 对齐、签名与验签、构建历史，以及 ADB 安装、启动和卸载。
- 新增版本对比、权限和 SDK 识别、网络字符串、ELF 导出符号与 JSON、HTML、CSV 报告。
- 新增可选 AI 流式请求、系统密钥存储、界面偏好和签名发布包的更新入口。

## 0.2.0

- 集成 JADX 与 Apktool，支持后台反编译、实时日志、取消任务及按工作区复用结果。
- 增加 Java、Smali、解码资源和清单的只读浏览。支持按路径筛选、搜索代码内容并跳转到命中行，以及导出 Java。
- JADX 产生部分结果时保留可浏览文件，并在 Java 视图显示提示。
- 按原始 ZIP 条目名区分大小写，允许导入包含 `res/9N.9.png` 与 `res/9n.9.png` 等不同条目的 APK。

## 0.1.0

- 建立 Electron、Vue 3、TypeScript、Vite、Element Plus、Pinia、Monaco 工作台。
- 接入文件选择及拖放导入、APK 校验、SHA-256 本地缓存和工作区历史。
- 接入 aapt2 包信息、图标和 apksigner 签名验证；显示 DEX、ABI、任务与日志。
- 虚拟文件树、文件路径筛选、只读文本及位图预览，补充单元和真实 APK 桌面验收。
