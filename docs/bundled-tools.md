# Apple Silicon 内置工具

- [JADX 1.5.6](https://github.com/skylot/jadx/releases/tag/v1.5.6) 和 [Apktool 3.0.3](https://github.com/iBotPeaches/Apktool/releases/tag/v3.0.3) 均使用随包附带的 Apache 2.0 许可证。发行包中的内嵌声明也保留。
- [Eclipse Temurin 25.0.5+8 ARM64 JRE](https://github.com/adoptium/temurin25-binaries/releases/tag/jdk-25.0.5%2B8) 的许可证和第三方声明见 `runtime/legal`。[对应源码包](https://github.com/adoptium/temurin25-binaries/releases/download/jdk-25.0.5%2B8/OpenJDK25U-jdk-sources_25.0.5_8.tar.gz)
- Android SDK Build Tools 随包包含 AAPT2、zipalign、其链接的 C++ 运行库和 apksigner。Platform Tools 随包包含 adb。许可证和组件声明见各目录中的 `NOTICE.txt`，版本见 `source.properties`。公开再分发时按各组件对应的许可证核对发布材料。[Android SDK 条款第 3.5 节](https://developer.android.com/studio/terms)
